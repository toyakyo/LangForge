# LangForge



AI-powered game screenshot translator with support for multiple translation engines.

## Features

- 🎮 Game screenshot translation
- 🌐 Support for multiple AI engines (Gemini, Claude, OpenAI, etc.)
- 🔤 Local OCR with EasyOCR
- 💾 Translation history logging
- 🎨 Multi-language UI (Chinese/English)
- ⚡ Real-time translation

## Installation

### Option 1: Download Pre-built Executable
1. Download `LangForge.exe` from GitHub Releases
2. Run directly (no installation required)
3. Verify SHA256: `[SHA256_HASH]`

### Option 2: From Source
```bash
git clone https://github.com/toyakyo/LangForge.git
cd LangForge
pip install -r requirements.txt
python main.py
```

## Usage

1. Launch LangForge.exe
2. Configure translation engine (set API keys)
3. Capture game screenshots
4. Translations appear automatically

## Supported Engines

- Google Generative AI (Gemini)
- Anthropic (Claude)
- OpenAI (GPT)
- Groq
- Mistral
- OLLAMA (Local)

## Requirements

- Python 3.8+
- Windows 10/11
- Internet connection (for cloud API)
